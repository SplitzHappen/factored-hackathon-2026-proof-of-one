# R3F UI shell review boundary

Review is limited to whether the branch adds a narrow local UI shell over the existing synthetic API without changing backend authority.

Accepted evidence for this branch:

- static file scope;
- route availability tests;
- OpenAPI-hidden shell tests;
- existing API-flow preservation test;
- local manual screenshot/video capture after checkout.

Not accepted as claims from this branch:

- hosted CI status;
- live provider readiness;
- held-out evaluation completion;
- production readiness;
- final judge submission approval.
